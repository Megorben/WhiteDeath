# White Death

Контент-мод для [Mindustry](https://github.com/Anuken/Mindustry) (v146+). Написан на HJSON, поэтому работает и на ПК, и на Android.

![icon](icon.png)

## Что добавляет

| Контент | Описание |
|---|---|
| **Белая смерть** (турель 2×2) | Дальнобойная снайперская турель: радиус 440, медленная перезарядка, пробивающие пули. Стреляет по земле и воздуху. В дереве исследований идёт после Lancer. |
| **Ледяной патрон** (предмет) | Лучшие патроны для «Белой смерти»: урон по площади, заморозка цели, двойной боезапас. |
| **Ледяной пресс** (крафтер 2×2) | Из 1 титана, криогенной жидкости и энергии делает 2 ледяных патрона. В дереве исследований идёт после печи для метастекла. |

### Патроны «Белой смерти»

| Патрон | Урон | Особенности |
|---|---|---|
| Графит | 140 | Пробивает 2 цели |
| Титан | 110 | Пробивает 4 цели, игнорирует броню, стреляет на 20% быстрее |
| Ледяной патрон | 160 + 45 по площади | Пробивает 2 цели, замораживает на 5 с, 2 выстрела с одного патрона |

## Установка

**Через игру:** «Моды» → «Импорт мода» → «Импорт из GitHub» → `Megorben/WhiteDeath`. Для этого репозиторий должен быть публичным.

**Вручную:** скачайте репозиторий в ZIP и положите архив в папку модов:
- Windows: `%AppData%/Mindustry/mods/`
- Linux: `~/.local/share/Mindustry/mods/`
- Android: через «Импорт мода» в игре

## Структура

```
mod.hjson            — метаданные мода
content/blocks/      — турель и крафтер
content/items/       — ледяной патрон
bundles/             — переводы (en, ru)
sprites/             — текстуры
```
